## 📌 Overview

**Ashi's Kitchen** is a responsive digital franchise prospectus and brand landing platform designed for Anjar Foods & Beverages Pvt Ltd. The platform presents the franchise model, menu highlights (vegetarian & non-vegetarian), ROI calculations, and investor inquiry funnels.

---

## ✨ Features

- **🏆 Luxury Culinary Design:** Custom palette featuring forest green, gold accents, and vintage editorial typography (Fraunces & Manrope).
- **📈 Franchise Investor Calculator:** Interactive ROI breakdown, investment tiers, and profit margin analysis.
- **📱 Fully Responsive:** Adaptive layout engineered for mobile and desktop screens.
- **⚡ Zero External Bloat:** Self-contained single-page architecture with inline styling and responsive micro-interactions.

## 🚀 Quick Preview

Simply open `index.html` in any modern web browser or serve locally:
```bash
python -m http.server 8000
```
